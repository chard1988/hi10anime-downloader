Hi10 Download Manager — v0.3.0-beta.2 testing prerelease (MIT)

Recommended: pull ghcr.io/chard1988/hi10anime-downloader:0.3.0-beta.2.
Full instructions are in docs/UNRAID_INSTALL.md and the release's INSTALL.md.

Fresh install:
1. Download this source bundle and SHA256SUMS from the GitHub prerelease.
2. Verify the archive checksum, extract it and run sh install.sh as root in the
   unRAID Terminal. The script pulls the image and installs a template; it does
   not start downloads. Package visibility must be Public for anonymous pulls.
3. Docker -> Add Container -> hi10-downloader; set the app password and host
   folders mapped to /config and /downloads. Both must be writable by 99:100.
4. Apply, open WebUI, import your existing Hi10 session, and test selected files.

Existing install:
Stop jobs/container, back up all appdata and the download manifest, then edit
Repository to the versioned image above. Keep existing paths, port and password.
Apply recreates the container. Do not delete appdata or videos. Existing templates
are preserved by install.sh, so update Repository manually when one already exists.

Extra Parameters:
--init --shm-size=1g --stop-timeout=75 --cap-drop=ALL --security-opt=no-new-privileges

Use session import from the bundled browser-extension helper. This beta records
security findings and hardened embedded-browser compatibility failures. It is
for private LAN/Tailnet testing, not a stable release or CA listing. See the
attached scan/SBOM/validation reports. Do not enable Privileged to make login work.

Explicit local source build: sh install.sh --build-local
This is not needed for the normal pull-based installation and can differ from
the published image digest. No registry password should be put in this bundle.
