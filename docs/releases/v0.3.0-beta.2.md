# Hi10 Download Manager v0.3.0-beta.2

**Testing prerelease — not a stable/production release.** Linux/amd64.

This beta adds same-quality mirror-link checks before downloading, reuse of
existing Chrome/Edge sessions through a site-scoped exporter, and sandboxed
installed-browser selection for desktop capture. It also includes the earlier
queue/grouping, session, recovery and resource-limit work.

## Install on unRAID

Image: `ghcr.io/chard1988/hi10anime-downloader:0.3.0-beta.2`.
Follow [the installation/upgrade guide](https://github.com/chard1988/hi10anime-downloader/blob/master/docs/UNRAID_INSTALL.md),
or the attached INSTALL.md. Existing users should edit Repository and preserve
/config and /downloads; a complete uninstall is not required. Back up appdata and
the download manifest before upgrading.

GitHub initially makes new packages private. The owner must set this container
package to Public once before anonymous pulls work. No personal access token is
needed on unRAID once the package is public.

## Known beta limitations and security findings

The owner explicitly approved a testing beta with disclosed findings on 2026-11-17.
The attached scan contains all findings; no CVE suppression or stable-release
waiver is used. Read beta-validation.json, vulnerabilities.json and the SBOM before
choosing to run it. Use a private LAN/Tailnet and authorized content only.

The embedded Chromium sandbox can fail under hardened container/host settings.
Keep the non-root, cap-drop/no-new-privileges settings and import a session using
hi10-session-export.zip. Do not run privileged or disable sandboxing to work around
this limitation. Browser login success, CAPTCHA and mirror availability are not
guaranteed. No CAPTCHA bypass is implemented.

Only amd64 is tested. NAS filesystem behavior, multi-day soak, Tailscale hooks,
ARM, CA acceptance, signed attestations and stable-release readiness are not
certified by this beta. New queues need an explicit start; existing schedules
persist. Downloads interrupted mid-file restart from the beginning.
